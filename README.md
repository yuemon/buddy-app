# Buddy – push-ups & squats

A tiny offline-first PWA that counts push-ups and squats with your phone camera (or lets you log them by hand), tracks daily goals and streaks, and grows a cartoon Buddy as you train.

* All data stays on your device (localStorage). No accounts, no server.
* Works offline after the first load; the pose model runs on-device.
* Install: iPhone – Safari ▸ Share ▸ Add to Home Screen. Android – Chrome ▸ Install app.

Voice commands ("start", "pause", "done") use the browser's speech recognition, which needs a network connection in Chrome/Safari. Tap or raise a hand as an offline fallback.
